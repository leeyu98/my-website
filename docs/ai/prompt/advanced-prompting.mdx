在掌握了基础提示词技巧后，以下进阶方法可以进一步提升复杂任务的准确率。

## Self-Consistency（自一致性）

对同一问题独立采样多次，取**多数结果**。适合有明确答案的任务：

```text
同一个问题 → 让模型回答 5 次（temperature 0.7）
→ 取出现最多的答案作为最终结果
```

适用场景：数学推理、逻辑判断、分类任务。

## Tree of Thought（思维树）

不只是单向思考，而是**分叉推理，然后回溯选择最优路径**：

```text
# 问题：用 4 个数字 1, 3, 4, 6 算出 24

# 步骤 1: 生成 3 种可能的下一步
- 6 × 4 = 24
- 6 × 3 = 18  
- 4 × 3 = 12

# 步骤 2: 对每种选择分别评估可行性
- 6 × 4 = 24 → 剩余 1, 3，可以 24 × (3 - 2)...不行
- 6 × 3 = 18 → 剩余 1, 4，可以 18 + 6...剩余 4, 1 凑不出 6
- ...

# 步骤 3: 回溯并尝试新路径
- 6 ÷ (1 - 3/4) = 24 ✓
```

实际使用时不需要让模型真正生成树结构，可以通过多轮对话引导模型分步试探。

## Meta-Prompting（元提示）

用 LLM 来**生成和优化 prompt**：

```text
我要对以下 prompt 进行优化，请分析存在的问题并给出改进版本。

原始 prompt:
{你的 prompt}

请从以下维度分析：
1. 指令清晰度
2. 是否缺少必要约束
3. 是否存在歧义
4. 输出格式是否明确
```

也可以让模型自己迭代 prompt：输出 → 评估 → 改写 prompt → 重新输出。

## Structured Prompt Template

对于需要批量处理的任务，使用**结构化模板**：

```markdown
## Role
{角色描述}

## Context
{背景信息}

## Task
{具体任务}

## Constraints
- {约束 1}
- {约束 2}

## Output Format
{期望的输出格式}

## Examples
输入: {示例输入}
输出: {示例输出}
```

这种模板不仅在对话中好用，在程序化构建 prompt 时尤其重要（可维护、可复用）。

## Prompt Caching 策略

对于有大量固定上下文的场景（如 system prompt + 大量文档），注意利用模型的缓存机制：

1. **静态内容放前面**：system prompt、固定指令 → 可被缓存
2. **动态内容放后面**：用户问题、检索到的文档片段
3. **减少频繁修改**：避免每次请求都修改开头内容

Anthropic 和 OpenAI 都提供了 prompt caching，合理设计 prompt 结构可以减少 90% 的 token 成本。

## Hallucination（幻觉）缓解策略

| 策略 | 做法 |
| --- | --- |
| 引用原文 | 要求模型先引用再回答 |
| 明确边界 | "如果不知道，直接说不知道" |
| 给退路 | "如有疑问，请说明不确定的程度" |
| 多次验证 | 让模型自我检查答案，或两次回答比对 |
| RAG 加持 | 用检索结果作为事实锚定 |

```text
请回答以下问题。要求：
1. 先引用文档中的相关内容
2. 再给出你的结论
3. 如果文档中没有明确信息，请说明"根据文档无法确认"
4. 对不确定的部分，用 [不确定] 标记
```

## 总结

| 技巧 | 适用场景 | 成本 |
| --- | --- | --- |
| Self-Consistency | 有明确答案的问题 | 高（多次采样） |
| Tree of Thought | 多步骤推理 | 很高 |
| Meta-Prompting | Prompt 调优 | 中 |
| 结构化模板 | 批量/程序化调用 | 低 |
| 幻觉缓解 | 任何需要准确性的场景 | 低～中 |
