## 命令模式

|    键盘    | 功能                                                     |
| :--------: | :------------------------------------------------------- |
|    `i`     | 切换到输入模式，在光标位置输入文本                       |
|    `x`     | 删除光标位置的文本，如果是竖线光标，依次删除光标后的文本 |
|    `a`     | 切换到输入模式，在光标下一个位置开始输入                 |
|    `o`     | 切换到输入模式，在当前行的上方插入一个新行               |
|    `O`     | 切换到输入模式，在当前行的下方插入一个新行               |
|    `dd`    | 剪切当前行                                               |
|    `yy`    | 复制当前行                                               |
|    `p`     | 粘贴剪贴板内容到光标下一行                               |
|    `P`     | 粘贴剪贴板内容到光标上一行                               |
|    `u`     | 撤销上一次操作                                           |
| `Ctrl` `r` | 重做上一次操作                                           |
|    `:`     | 切换到命令模式，以执行 `vim` 命令                        |
|    `:w`    | 保存文件                                                 |
|    `:q`    | 退出 `vim` 编辑器                                        |
|   `:wq`    | 保存并退出 `vim` 编辑器                                  |
|   `:q!`    | 不保存本次修改，退出 `vim` 编辑器                        |

## 输入模式

| 键盘  | 功能                   |
| :---: | :--------------------- |
| `Esc` | 退出输入模式，进入命令模式 |
