## 变量

### 变量的要求和约定

1. 只能包含字母、数字、下划线，不能以数字开头
2. 不能有空格
3. 不能是关键字
4. 尽量使用小写，有一定意义
5. 变量名区分大小写

## 字符串

1. `str.title()` 首字母大写
2. `str.upper()` 全大写
3. `str.lower()` 小写
4. `+` 可以直接拼接字符串
5. 支持 `\t`、`\n` 等转义字符
6. `str.strip()` 删除两端空格
   - `str.lstrip()` 删除开头空格
   - `str.rstrip()` 删除末尾空格

## 数字

- 整数：`**` 表示乘方
- 浮点数：存在不精确的问题
- `str(data)` 将数据转化为 string 类型，因为它不能自动转换

## 列表

list，就像是 js 中的数组。

- 通过下标访问，index 从 0 开始
- 列表中的每一项类型可以是不同的

### 修改

`list[index] = new_data`，<Emphasis>new_data 可以是任意的类型</Emphasis>

### 增加

- `list.append(new_data)`：末尾追加数据，<Emphasis>new_data 可以是任意的类型</Emphasis>
- `list.insert(index, new_data)`：插入一个数据。如果 index 大于当前 list 的长度，只会追加到最后；也可以是负数，从右边开始

### 删除

- `del list[index]`：删除某个元素。跟 js 不一样，直接就删掉了，后面的会补上来，不会是 undefined 占位。index 超出会报错，可以是负数
- `list.pop()`：删除末尾的元素
- `list.pop(index)`：删除索引处的元素
- `list.remove(data)`：按照值来删除

:::tip
跟 js 不一样，删除元素后后面的会自动补上来，不会是 undefined 占位。index 超出会报错，可以是负数。
:::

### 排序

- `list.sort()` 永久排序，会改变原来的 list
  - 默认按字母顺序排列
  - 排序的 list 数据类型需要一致，否则会报错
  - 使用参数 `reverse=True`，实现倒序排列
- `sorted(list)` 临时排序，不会改变原来的 list
  - 也可以传入第二个参数 `reverse=True`
- `list.reverse()` 按原来 list 倒序排列，永久性排序。可以再次使用 `reverse()` 倒回来

### 长度

`len(list)` 获取 list 的长度

### 切片

`list[start:end]` 就是截取 list 的一部分，包含 start，不包含 end

- start 不写，默认从 0 开始；不写 end 就会截取到末尾；只写冒号 `:` 也可以截取整个 list

#### 遍历切片

结合 for 循环遍历

```py
my_list = ['name', 'age', 'gender', 'job']

for val in my_list[0:3]:
    print(val)
```

切片可以用来复制 list。这和 js 中的引用类型类似（深浅拷贝）：

- `list1 = my_list` 像这种直接赋值的话，其中一个改变时，另一个也会变
- `list1 = my_list[:]` 像这种复制的话就不会

```py
my_list = ['name', 'age', 'gender', 'job']
list1 = my_list  # 直接赋值
# 排序后两者都会变

list1 = my_list[:]  # 拷贝
# 排序后只有原列表改变

my_list.sort()  # 排序会改变原列表
print(my_list, list1)
```

## 元组

- 可以理解为不可以修改的 list，用 `()` 括起来
- 遍历方式与 list 相同，`tuple[index]`
- 元组的元素不可以修改，但是整个元组可以重新赋值，也就相当于重新定义了

## 字典

类似于 js 中的对象，是键值对的形式。

- 使用 `{}` 括起来的一些键值对
- 访问方式只能使用 `obj['key']`。同样是通过 key 访问，但是不能使用打点 `.` 的形式，也不能使用 index 的形式
- js 中访问对象的属性时可以使用 `obj.key` 和 `obj['key']`

```py
person = {'name': 'Ryan', 'age': 22}
print(person['name'])
```

### 添加或者修改

也使用同样的 `obj['key']` 访问方式

```py
person = {'name': 'Ryan', 'age': 22}
person['name'] = "Dylan"
print(person)
# {'name': 'Dylan', 'age': 22}
```

### 删除键值对

`del obj['key']`：删除了就永久消失了

### 遍历字典

#### 遍历所有<Emphasis>键值对</Emphasis>

使用 `obj.items()`

```py
person = {'name': 'Ryan', 'age': 22}
for key, value in person.items():
    print(key + ': ' + str(value))
# name: Ryan
# age: 22
```

:::info
`items()` 不能用于遍历 list
:::

#### 遍历所有的<Emphasis>键</Emphasis>

使用 `obj.keys()`

```py
person = {'name': 'Ryan', 'age': 22}
for key in person.keys():
    print(key)
# name
# age
```

#### 遍历所有的<Emphasis>值</Emphasis>

使用 `obj.values()`

```py
person = {'name': 'Ryan', 'age': 22}
for value in person.values():
    print(value)
# Ryan
# 22
```
