## 4 操作列表

### 4.1 遍历

for 循环：类似于 js 中的 for...in

```python
for item in list:
    print(item)
```

- 注意冒号
- 记得缩进

### 4.2 创建数值列表

#### 1) range(start,end)

可以快速创建数组列表，包含开始 start，不包含 end

```py
# 打印 1 ~ 7
for data in range(1, 8):
    print(data)
```

#### 2) list()

可以直接将 range()直接转成列表

```py
# [1, 2, 3, 4, 5, 6, 7]
list1 = list(range(1, 8))
print(list1)
```

#### 3) range(start, end, step)

指定步长，类似于 matlab 中矩阵

```py
# 打印 1 3 5 7
for item in range(1, 8, 2):
    print(item)
```

#### 4) 统计函数

- min(list) 最小值
- max(list) 最大值
- sum(list) 求和

```py
list = [0, 9, 5, 3, 2, 8, 6]
print(min(list), max(list), sum(list))
# 0 9 33
```

#### 5) 列表解析

```py
sq = []
for val in range(1, 11):
    sq.append(val**2)
print(sq)
```

可以简写成下面的代码

```py
sq = [val**2 for val in range(1, 11)]
print(sq)
```

### 4.3 使用列表的一部分

#### 1) 切片

list\[start\:end] 就是截取 list 的一部分，包含 start 不包含 end

- start 不写，默认从 0 开始；不写 end 就会截取到末尾；只写冒号:也可以截取整个 list

#### 2) 遍历切片

- 就是结合 for 循环遍历

```py
list = ['name', 'age', 'gender', 'job']

for val in list[0:3]:
    print(val)
```

- 切片可以用来复制 list。这和 js 中的引用类型类似（深浅拷贝）：
  - `list1 = list` 像这种直接赋值的话，其中一个改变时，另一个也会变
  - `list1 = list[:]` 像这种复制的话就不会。

```py
list = ['name', 'age', 'gender', 'job']
list1 = list # 直接赋值
# 结果['age', 'gender', 'job', 'name'] ['age', 'gender', 'job', 'name']

list1 = list[:] # 拷贝
# 结果 ['age', 'gender', 'job', 'name'] ['name', 'age', 'gender', 'job']

list.sort() # 排序会改变原数组
print(list, list1)
```

### 4.4 元组

- 可以理解为不可以修改的 list，用 `()` 括起来
- 遍历方式与 list 相同，list\[index]
- 元组的元素不可以修改，但是整个元素可以重新赋值，也就相当于重新定义了

#### 3) 比较数字

- 用法和其他语言类似：`==,!=,>,<,>=,<=`

<font color="red">注意</font>

- 比较两个 `字符串` 也是可以使用 `>,<,>=,<=` 依次顺位比较 ASCII

```py
print('ab'>'ba') # False
```

- 比较两个 `list` 时，依次顺位比较 list 元素的 ASCII，与 list 长度无关

```py
print([1,2,7]>[1,2,5,8,9]) # True
```

## 6 字典

类似于 js 中的对象，是键值对的形式。

- 使用 {} 括起来的一些键值对
- 访问方式只能使用 `obj['key']`。同样是通过 key 访问，但是不能使用打点.的形式，也不能使用 index 的形式。
- js 中访问对象的属性时可以使用 `obj.key` 和 `obj['key']`

```py
person = {'name': 'Ryan', 'age': 22}
print(person['name'])
```

### 6.1 添加或者修改

- 也使用同样的 `obj['key']` 访问方式

```py
person = {'name': 'Ryan', 'age': 22}
person['name'] = "Dylan"
print(person)
# {'name': 'Dylan', 'age': 22}
```

### 6.2 删除键值对

- `del obj['key']`
  - 删除了就永远消失了

### 6.3 遍历字典

#### 1) 遍历所有==键值对==

- 使用 `obj.items()`

```py
person = {'name': 'Ryan', 'age': 22}
for key, value in person.items():
    print(key + ': ' + str(value))
# name: Ryan
# age: 22
```

- 试过了，这个 item()是不能用于遍历 list 的
