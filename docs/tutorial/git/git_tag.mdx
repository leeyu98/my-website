## 创建 tag

```bash
git tag <tagname> -m <message>
```

## 查看

```bash
# 列出所有的 tag
git tag --list # or -l
```

## 重命名

```bash
git tag <newname> <oldname>
git tag -d <oldname>
git push --tags
```

## 修改描述

```bash
git tag -m <message> -e <tagname> -f
git push --tags -f
```
