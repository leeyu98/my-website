## Mac 无法切换桌面

**问题描述:** 触控板滑动、快捷键无法切换多桌面<br/>
**解决方案:** 重启 Dock 栏

```bash
killall Dock
```

## 已损坏，无法打开。 您应该将它移到废纸篓”

默认情况下，`macOS` 会阻止用户安装和运行来自未知开发者的应用程序。这是为了保护用户免受恶意软件的攻击。

**1. 启用任何来源选项**

```bash
sudo spctl --master-disable
```

执行并输入密码之后，可以在「系统设置」->「隐私与安全性」->「安全性」->「允许以下来源的应用程序」中选择「任何来源」。

如果打开应用仍然提示「Apple 无法验证“Sketch.app”是否包含可能危害 Mac 安全或泄漏隐私的恶意软件。」则需要在「系统设置」->「隐私与安全性」->「安全性」已阻止的 App 中选择「仍要打开」。

**2. 移除外部扩展属性**

```bash
sudo xattr -r -d com.apple.quarantine /Applications/Sketch.app
```

输入密码之后，重新打开应用即可。

**快速获取应用路径**

按住 <kbd>⌘</kbd> 键，点击 `docker` 栏应用图标，可快速在 `Finder` 中定位到应用，拖动应用到终端中即可。
